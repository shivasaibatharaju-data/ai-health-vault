# Screenshots

Portfolio screenshots of the application belong in this directory. Use synthetic records only and verify that no personal or protected health information is visible.

Recommended captures:

- landing page hero at desktop and mobile widths
- SaaS dashboard using synthetic demo records
- drag-and-drop upload state without a real medical file selected
- medical records library with synthetic filenames
- AI assistant with clearly synthetic conversation content
- health timeline with fictional providers and events

Before committing a screenshot:

1. Inspect every visible name, date, provider, filename, and message.
2. Confirm browser extensions, account emails, tokens, and local paths are hidden.
3. Use PNG or WebP and keep the image reasonably compressed.
4. Add descriptive alt text wherever the screenshot appears in documentation.

`app-dashboard.png` is the main README preview and should represent the current frontend.
